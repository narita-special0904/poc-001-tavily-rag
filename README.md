### RAG with Tavily API 

#### 🎯 目的
1. Tavily APIにより企業名から適切な情報を取得出来るか検証
2. LangGraph + Tavily APIで適切な状況で検索→検索結果をLLMのコンテキストに入れて回答

#### 🗒️ 実行コマンド
1. Tavily APIにより企業名から適切な情報を取得出来るか検証
```bash
$ uv run tavily_search.py
```

2. LangGraph + Tavily APIで適切な状況で検索→検索結果をLLMのコンテキストに入れて回答
```bash
$ uv run rag_with_tavily.py
```
